## Phase 1: Fix DPLL Dead Code Bug (Critical, 3 minutes)

### Problem
[`src/Linter/SAT.hs` lines 364-370](../../../src/Linter/SAT.hs#L364-L370): The DPLL branch always returns `[]` regardless of result — the `else` clause is identical to `then`:

```haskell
-- CURRENT (BROKEN):
dpllContradictions =
    if null nonHorns || not (runDPLL clauses)
    then []
    else []   -- ← DEAD CODE: always empty
```

### File: `src/Linter/SAT.hs`

**Replace lines 364-368** with:

```haskell
        -- 3. If non-Horn clauses exist, also verify with DPLL
        dpllContradictions =
            if null nonHorns || runDPLL clauses
            then []
            else [dpllFallbackChain]

        dpllFallbackChain = DerivationChain
            { chainConcept   = Nothing
            , chainDerived   = ""
            , chainPath      = []
            , chainConflict  = ""
            , chainOrigin    = PropositionalAxiom 0 Top
            , chainFormatted = "Semantic contradiction: Non-Horn propositional clauses are jointly unsatisfiable (DPLL)."
            }
```

> [!IMPORTANT]
> Note the logic flip: `not (runDPLL clauses)` → `runDPLL clauses`. `runDPLL` returns `True` when SAT (satisfiable) and `False` when UNSAT. So the original guard `not (runDPLL clauses)` was correct for "is it unsat?" but the body was wrong. The fix keeps the original semantics: skip when empty OR satisfiable; report when UNSAT.
>
> Actually re-reading: `if null nonHorns || not (runDPLL clauses) then [] else []`. Both branches return `[]`. The condition `not (runDPLL clauses)` means "DPLL says UNSAT" → `then []` (bug: should report). The `else` means "DPLL says SAT" → `[]` (correct: nothing to report). So the fix is:
>
> ```haskell
> if null nonHorns || runDPLL clauses  -- no non-Horn clauses, or they're satisfiable
> then []
> else [dpllFallbackChain]            -- non-Horn clauses are UNSAT
> ```

extractUserPreds :: Env -> FOL -> [(Name, Int)]
extractUserPreds env f = case f of
    ForAll _ b -> extractUserPreds env b
    Exists _ b -> extractUserPreds env b
    TypedForAll _ _ b -> extractUserPreds env b
    TypedExists _ _ b -> extractUserPreds env b
    And a b -> extractUserPreds env a ++ extractUserPreds env b

    Not a -> extractUserPreds env a
