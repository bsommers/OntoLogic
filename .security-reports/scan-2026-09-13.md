## What Your Code Does RIGHT

> Security strengths found in this codebase. These are good practices to preserve and extend.

### 1. Environment-Driven Credential Management — `examples/batch_loader.py:6-8`
Credentials and URIs are dynamically sourced from `os.getenv("NEO4J_USER")` and `os.getenv("NEO4J_PASSWORD")`, eliminating secret leakage in source control.

### 2. Resource Management via Context Managers — `examples/batch_loader.py:11`
File descriptors are wrapped with `with open(..., mode="r", encoding="utf-8") as f:`, ensuring reliable cleanup and preventing resource leaks.

### 3. Safe Subprocess Execution Without Shell Evaluation — `src/Main.hs:117,126`
Visualizer renderer invocation uses Haskell's `System.Process.callProcess` with an explicit argument vector rather than shell command strings (`callCommand`), completely eliminating command injection risks from arbitrary file paths.

### 4. Cypher Literal & Identifier Sanitization — `src/Emitters/Neo4j.hs:28-31`
The Neo4j emitter implements `escapeCypherString` escaping single quotes (`\'`) and backslashes (`\\\\`), preventing Cypher injection when emitting ontology names and property values.

### 5. Parameterized Database Queries — `examples/batch_loader.py:14`
Uses parameterized Cypher execution (`session.run("MERGE (n:Device {id: $id}) SET n += $props", id=..., props=...)`), isolating untrusted CSV input from query syntax.

### 6. Canonical Path Resolution & Import Cycle Protection — `src/Loader.hs:38-50`
Module loader uses `canonicalizePath`, traversal stack tracking, and visited sets, defending against path traversal exploits and circular import recursion denial-of-service.

### 7. Runtime Constraint Enforcement via Jakarta, Pydantic, Rust & Go — `src/Emitters/`
Generated code emits strict schema constraints (`@NotNull`, `@Min`, `@DecimalMax`, Pydantic `Field(ge=..., le=...)`, Rust `validate()`, Go `Validate()`) preventing invalid state propagation at runtime.

### 8. Container Configuration Variable Interpolation — `docker-compose.yml:6`
Environment variables use fallback syntax (`${NEO4J_AUTH:-neo4j/password}`) rather than hardcoded credentials.

### 9. Secure Script Installation Procedure — `setup.sh:31-36`
Installer uses `mktemp` and inspectable script execution rather than blind `curl | bash` pipelines.
